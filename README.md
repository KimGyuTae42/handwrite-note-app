# ✍️ 손글씨 인식 노트

> 태블릿이나 컴퓨터에서 펜으로 자유롭게 필기하면, 글씨를 자동으로 인식해서 내가 고른 글꼴의 텍스트로 바꿔주는 웹 노트 앱

정보과학 프로젝트로 만든 웹 서비스입니다. 설치 없이 브라우저에서 동작하고, 계정으로 로그인하면 **여러 기기에서 같은 노트를 이어서** 쓸 수 있습니다.

---

## 1. 어떤 서비스인가요?

**한 줄 소개**
사용자가 노트에 손으로 필기하면 → 앱이 글자를 인식해서 → 원하는 글꼴·색의 깔끔한 텍스트로 바꿔준다.

**이런 사람을 위해 만들었어요**
- 수업 시간에 패드로 필기하는 고등학생·대학생, 회의·세미나에서 메모하는 직장인
- 악필이라 나중에 자기 필기를 못 알아보거나, 친구와 필기를 공유할 때 글씨가 안 읽히는 사람
- 필기한 내용을 보고서로 옮겨 적어야 하는데 타자가 느린 사람

**핵심 아이디어**
일반 OCR처럼 사진 한 장을 통째로 인식하는 방식이 아니라, **쓰는 도중에** 이어 쓴 글자를 하나의 묶음으로 보고 실시간으로 변환합니다. 줄이나 칸에 맞출 필요 없이 **노트의 아무 위치에나** 써도 되고, 변환된 텍스트는 원래 쓴 자리와 크기를 최대한 유지합니다. 인식에 자신이 없으면(신뢰도가 기준 미만이면) 엉뚱한 글자로 바꾸지 않고 **손글씨를 그대로 둡니다.**

---

## 2. 입력 → 처리 → 출력 (IPO)

| 단계 | 내용 |
|---|---|
| **입력** | 펜/붓/하이라이터/지우개/올가미로 노트에 필기, 펜 색·두께, 변환할 글꼴·템플릿 선택 |
| **처리** | ① 가까이 있거나 이어서 쓴 획을 한 묶음으로 그룹핑 → ② 쓰기를 멈추면(0.8초) 해당 묶음을 이미지로 잘라냄 → ③ 글자 단위로 분할 → ④ **직접 학습한 CNN**으로 글자 판별(부족하면 Tesseract.js로 보조) → ⑤ 신뢰도가 기준(기본 80%) 이상이면 변환, 미만이면 손글씨 유지 |
| **출력** | 인식된 글자만 선택한 글꼴·색의 텍스트박스로 교체(위치 유지). 텍스트박스는 이동·크기조절·수정 가능 |
| **저장** | 폴더·노트·필기·템플릿·글꼴·설정을 계정별로 서버(Supabase)에 자동 저장 → 다른 기기에서 불러오기 |

## 3. 주요 기능

### 필기
- **도구**: 만년필, 붓, 하이라이터, 지우개(획 일부만 지움), 올가미(선택 후 이동·삭제), 선택
- **색·두께**: 색 3종 + 원하는 색 추가, 두께 3단계, 실행취소/다시실행
- **태블릿 최적화** (Apple Pencil · 삼성 S Pen 공통, 브라우저 표준 Pointer Events 사용)
  - 필압에 따라 선 굵기 변화
  - `getCoalescedEvents`로 빠르게 써도 끊기지 않는 부드러운 선
  - **팜 리젝션**: 펜 사용 중 손바닥 터치 무시, 접촉 면적이 큰 터치도 손바닥으로 간주해 무시
  - 두 손가락 **핀치 줌**(50%~400%), 필기 중 두 번째 손가락이 닿으면 그 획은 취소하고 줌으로 전환

### 손글씨 → 텍스트
- 한글 자모 · 영문 대/소문자 · 숫자 · 기호(`+ - < > [ ] { } | /`) 인식
- 인식 신뢰도 기준을 설정에서 조절(30~95%)
- 변환된 텍스트박스: 클릭=선택, 드래그=이동, 모서리 손잡이=크기조절(글자 크기도 같이), 더블클릭=내용 수정, `Delete`=삭제

### 노트 관리
- 폴더 트리 + 노트 목록, 새 폴더/노트, 이름 바꾸기(더블클릭), 휴지통, 검색
- **한 노트에 여러 페이지**: 상단 페이지 바에서 이동, `＋ 페이지`로 현재 페이지 **바로 뒤**에 빈 페이지 추가
- 여러 노트를 탭으로 동시에 열기

### 템플릿 · 글꼴
- 기본 템플릿 6종(모눈 계열) 내장, **PDF를 올리면 페이지마다 템플릿으로 자동 변환**(pdf.js)
- 손글씨 글꼴 2종 내장, **TTF 파일을 올려서 글꼴 추가**(실제로 로드해서 미리보기)

### 계정 · 동기화
- 이메일/비밀번호 회원가입·로그인(Supabase Auth)
- 변경할 때마다 자동 저장(0.7초 디바운스), 다른 기기에서 같은 계정으로 로그인하면 그대로 불러옴
- Supabase 설정이 없으면 "로그인 없이 이 기기에서만" 로컬 모드로 사용 가능

## 4. 손글씨 인식 모델 (CNN)

앱의 1순위 인식기는 이 프로젝트에서 **직접 학습한 CNN**이고, 신뢰도가 낮을 때만 범용 OCR(Tesseract.js)이 한 번 더 시도합니다.

- **클래스 102개**: 한글 자모 30 · 영문 대문자 26 · 소문자 26 · 숫자 10 · 기호 10
- **구조**: 입력 32×32 흑백 → Conv(32)·Conv(64)·Conv(96) 각각 BatchNorm+ReLU(+MaxPool) → Dense(192) → Dropout → Softmax. 가중치 약 5MB, 브라우저에서 TensorFlow.js로 실행
- **학습 데이터**: 한글 자모 손글씨, HASY v2(숫자·영문·기호), A–Z 손글씨(NIST 계열), 숫자 손글씨(MNIST 계열). 회전·이동·확대·획 굵기 변화로 증강하고, 실제 앱의 전처리(글자 영역 크롭 → 정사각형 → 32×32)와 동일하게 맞춤
- **성능** (검증 2,707장): 전체 93.1% · 한글 자모 98.3% · 기호 97.4% · 숫자 95.5% · 대문자 96.2% · 소문자 75.9%
- **브라우저 실측** (학습에 쓰지 않은 이미지): 숫자 98.8%, 대문자 94.2%

학습 과정·데이터 출처·재학습 방법은 [`training/README.md`](training/README.md)에 있습니다.

## 7. 실행 방법

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 배포용 빌드(dist/)
```

로그인/동기화를 쓰려면 프로젝트 루트에 `.env.local`을 만들고 Supabase 값을 넣습니다. (`.env.example` 참고)

```
VITE_SUPABASE_URL=https://xxxx.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
```

그리고 Supabase **SQL Editor**에서 `supabase/schema.sql`을 한 번 실행하면 됩니다.
GitHub·Vercel·Supabase를 웹사이트에서 설정하는 방법과 자주 만나는 오류는 [`docs/SETUP.md`](docs/SETUP.md)를 보세요.

> 인식 라이브러리(TensorFlow.js, Tesseract.js, pdf.js)는 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 8. 한계와 앞으로 할 일

**현재 한계**
- **완성형 한글(가, 나, 힣…)은 인식하지 못하고 자모(ㄱ, ㅏ…) 단위로만** 인식합니다. 음절 조합이 1만 개 이상이라 별도 모델이 필요합니다.
- 글자를 서로 붙여 쓴 **필기체**는 글자 분할이 안 될 수 있습니다. 띄어 쓴 글씨에 가장 잘 맞습니다.
- 소문자 정확도가 가장 낮습니다. `c/C`, `o/O/0`, `l/I/1`처럼 모양이 같은 글자는 구분이 본질적으로 어렵습니다. 소문자 `t`는 실제 필기 데이터가 없어 합성 데이터로 학습했습니다.
- 내보내기(⇪) 버튼은 아직 동작하지 않습니다.
- 서버 저장은 계정당 JSON 한 덩어리로 저장하는 단순한 구조라서, 두 기기에서 동시에 편집하면 나중에 저장한 쪽이 덮어씁니다. 템플릿·글꼴 파일이 많아지면 저장 용량도 커집니다.
- 무료 Supabase 프로젝트는 오래 쓰지 않으면 자동으로 일시정지됩니다.

**앞으로**
- 완성형 한글 인식(음절 단위 모델), 소문자·기호 데이터 보강
- 대소문자·`0/O` 구분을 글자 크기·위치로 돕는 후처리
- 노트 내보내기(PNG/PDF), 폴더/노트/템플릿을 각각의 DB 테이블로 분리
- 두 기기 동시 편집 충돌 처리
